# Authentication — Firebase 身份驗證

- **功能：**
    - 管理匿名身分，為 App / Auth / AppClient 的後端
    - Anonymous Provider 啟用；既有 Google 與 Apple Provider 留存，無 UI 使用
    - App Check 防止未授權 API 存取
    - 身分刪除：由 CloudFunctions 以管理權限刪除 Auth 使用者紀錄
- **目的：**
    - 提供穩定 uid 作為 Firestore 存取控制的憑證來源與資料隔離邊界
- **做法：**
    - Firebase Authentication 集中管理；App Check 在 Firebase 端驗證請求來源合法性
    - 匿名帳號由 app 初次啟動自動建立；匿名自動清除設定保持關閉，防伺服端誤刪身分
    - legacy Google 與 Apple 登入帳號沿用原 uid，Provider 端無 UI 觸及
    - 身分刪除走清除所有資料流程，由 CloudFunctions 以管理權限執行
    - 清除後 app 自動重生新匿名 uid，不與舊資料歸戶
- **排除：**
    - 帳號密碼登入；其他第三方社交登入；帳號連結、帳號合併與客服搬家
    - 帳號 UI 與登入門
- **利弊：**
    - 免登入即可記帳與購買，符合 App Store 5.1.1 對可選註冊的要求
    - Firebase Authentication 免費使用，且與 Firestore 安全規則深度整合
    - 身分不可跨裝置自行還原，換機歸戶依賴整機還原；清除即斷根、資料保留最小化
